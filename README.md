# 三寶樹濕地與候鳥通道

新田與河套兩方案的互動展示網站，包含：

- 新田村視角：村口望向濕地的配對效果圖。
- 濕地鳥瞰：依新機位製作的我的方案渲染，保留城市前景、中央河灣與後方濕地的位置關係。
- 鋼筆圖集：我的方案八個視角的 Rhino 原生鋼筆模式輸出，可逐角度查看及下載原圖。
- 原模型對比：鳥瞰、高角度和俯視。
- 候鳥通道動畫：兩個同角度模型同步播放18秒候鳥飛行示意，可暫停、重播、拖動進度、關閉通道綠帶，並下載MP4。手機版上下排列；減少動態效果偏好下預設暫停。

新田村配對圖可直接拖動、使用滑桿或切換並排。新鳥瞰及鋼筆圖集單獨展示我的方案。手機亦可瀏覽。完整網站為靜態 HTML、CSS 和 JavaScript，無需登入。

效果圖為方案意象。新田村視角中，政府平台較村地面高約7米，按指定的相對高差作情境示意。原模型對比保留作配置參照。
候鳥動畫的綠帶寬度及鳥群展開為方案意圖示意，並非實測寬度、鳥類追蹤數據或生態模擬；兩側使用相同鳥群數量與時間。

網站地址見本倉庫 About 中的 Website。GitHub Pages 從 `main` 分支根目錄發布。

本機預覽：在倉庫目錄執行 `python -m http.server 8000`，再開啟 `http://localhost:8000`。亦可直接開啟 `index.html`。
